# SportMental (archivé)

Le projet SportMental a été supprimé. Ce dossier existe uniquement parce que le
projet Vercel `projets` utilise encore `SportMental` comme Root Directory :
`vercel.json` y désactive les déploiements pour qu'ils n'échouent plus.

Pour supprimer ce dossier, supprime d'abord (ou déconnecte) le projet Vercel
`projets`.
